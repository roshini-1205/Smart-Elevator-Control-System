# Smart Elevator Control System

## Overview

This project simulates a 4-floor elevator using Arduino Uno.

The system allows users to select floors using push buttons and displays elevator status on a 16×2 LCD.

---

## Features

- Floor Selection (1–4)
- Moving Up Indication
- Moving Down Indication
- Floor Monitoring
- Arrival Notification
- Emergency Stop Function
- LCD Interface

---

## Components Used

- Arduino Uno
- 16×2 LCD
- Potentiometer
- Push Buttons
- Buzzer
- Breadboard
- Jumper Wires

---

## Working

1. User selects a floor.
2. Elevator moves floor-by-floor.
3. LCD displays current status.
4. Buzzer sounds when destination is reached.
5. Emergency button stops operation.
